Overview

Kulture is a 3D mobile learning application designed for Grade 5 students, featuring Philippine cultural games aligned with the DepEd MAPEH curriculum. The application combines interactive gameplay with physics-based simulations to provide an engaging learning experience.

Key Features

  • Interactive 3D Philippine cultural games
  • Grade 5 educational content
  • Physics-based gameplay
  • DepEd MAPEH-aligned learning activities
  • Android mobile application
